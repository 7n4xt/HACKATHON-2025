# HACKATHON-2025

## How to Run the Website

### Using Live Server
1. Install the Live Server extension for your code editor (like VS Code)
2. Right-click on the `index.html` file or any other HTML page in the `pages` directory
3. Select "Open with Live Server"
4. The website will open in your default browser with automatic page reloading

### Navigation
- You can navigate between different sections using the menu at the top
- Main games available:
  - Carbon Clicker: A game about reducing carbon emissions
  - Recycle Rush: Test your recycling knowledge

### Project Structure
- `/pages`: Contains all HTML pages
- `/assets`: Contains CSS and audio files
- `/scripts`: Contains JavaScript files for each page
