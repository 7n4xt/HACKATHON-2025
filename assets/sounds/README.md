# Sound Effects for Carbon Clicker

This directory contains sound effects for the Carbon Clicker game.

## Credits

The sound effects should be royalty-free sounds suitable for:
- Click actions
- Upgrade purchases
- Victory sounds
- Game over sounds
- Background music (optional)

You can download free sounds from sites like:
- Freesound.org
- OpenGameArt.org
- Pixabay Sound Effects
